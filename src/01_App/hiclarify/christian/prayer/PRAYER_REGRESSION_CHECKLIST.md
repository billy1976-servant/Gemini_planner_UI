# Prayer App ΓÇö Regression Checklist

Run this checklist after each stabilization phase. All items must pass before proceeding.

## Room

- [ ] **Join as speaker** ΓÇö Can join room; see content stage and host controls.
- [ ] **Join as listener** ΓÇö Can join; hear/see stream; no host controls.
- [ ] **Leave room** ΓÇö Can leave; return to prayer base.

## Deck / slides

- [ ] **Select deck** ΓÇö Host can pick a deck; slides show in SlideViewer.
- [ ] **Change slide** ΓÇö Prev/next/jump work; current slide updates.
- [ ] **No deck / empty deck** ΓÇö Empty state shows: "No slide deck loadedΓÇª".

## Session pages

- [ ] **Save page** ΓÇö Host can save current view as session page; appears in SessionSlidesView.
- [ ] **Annotate screen** ΓÇö One-click capture adds session page; annotation visible.
- [ ] **Switch session slide** ΓÇö Navigate among saved pages.
- [ ] **No session pages** ΓÇö Empty state shows: "Save a page to see it hereΓÇª".

## Annotation

- [ ] **Draw** ΓÇö Strokes appear on overlay; persist on session slide when saved.
- [ ] **Clear / undo** ΓÇö Clear and undo (if present) work; no crash.

## Recording

- [ ] **Start recording** ΓÇö Recording starts; duration displays.
- [ ] **Stop recording** ΓÇö Stops; replay becomes available.

## Replay

- [ ] **Replay after stop** ΓÇö Video plays; session timeline and annotation timeline in sync with video time.

## Publish / export

- [ ] **Publish recording** ΓÇö Publish succeeds; no errors.
- [ ] **Export session** ΓÇö Download works (recording + manifest).

## Moderator panel

- [ ] **Open / close** ΓÇö Panel toggles.
- [ ] **Screen share** ΓÇö Start/stop screen share.
- [ ] **Mute participant** ΓÇö Mute/unmute works.
- [ ] **Mute self** ΓÇö Host mute toggle works.
- [ ] **Copy invite link** ΓÇö Clipboard gets room URL.
- [ ] **End room** ΓÇö Room ends; participants see updated state.

## Navigation

- [ ] **Player, library, live, room, admin** ΓÇö All routes load.
- [ ] **Back links** ΓÇö Back to prayer works.
- [ ] **Share URL** ΓÇö Share URL is correct.

## Console

- [ ] **No errors or warnings** ΓÇö No Prayer/room-related errors in console.
