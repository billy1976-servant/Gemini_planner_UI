# Prayer App — Regression Checklist

Run this checklist after each stabilization phase. All items must pass before proceeding.

## Room

- [ ] **Join as speaker** — Can join room; see content stage and host controls.
- [ ] **Join as listener** — Can join; hear/see stream; no host controls.
- [ ] **Leave room** — Can leave; return to prayer base.

## Deck / slides

- [ ] **Select deck** — Host can pick a deck; slides show in SlideViewer.
- [ ] **Change slide** — Prev/next/jump work; current slide updates.
- [ ] **No deck / empty deck** — Empty state shows: "No slide deck loaded…".

## Session pages

- [ ] **Save page** — Host can save current view as session page; appears in SessionSlidesView.
- [ ] **Annotate screen** — One-click capture adds session page; annotation visible.
- [ ] **Switch session slide** — Navigate among saved pages.
- [ ] **No session pages** — Empty state shows: "Save a page to see it here…".

## Annotation

- [ ] **Draw** — Strokes appear on overlay; persist on session slide when saved.
- [ ] **Clear / undo** — Clear and undo (if present) work; no crash.

## Recording

- [ ] **Start recording** — Recording starts; duration displays.
- [ ] **Stop recording** — Stops; replay becomes available.

## Replay

- [ ] **Replay after stop** — Video plays; session timeline and annotation timeline in sync with video time.

## Publish / export

- [ ] **Publish recording** — Publish succeeds; no errors.
- [ ] **Export session** — Download works (recording + manifest).

## Moderator panel

- [ ] **Open / close** — Panel toggles.
- [ ] **Screen share** — Start/stop screen share.
- [ ] **Mute participant** — Mute/unmute works.
- [ ] **Mute self** — Host mute toggle works.
- [ ] **Copy invite link** — Clipboard gets room URL.
- [ ] **End room** — Room ends; participants see updated state.

## Navigation

- [ ] **Player, library, live, room, admin** — All routes load.
- [ ] **Back links** — Back to prayer works.
- [ ] **Share URL** — Share URL is correct.

## Console

- [ ] **No errors or warnings** — No Prayer/room-related errors in console.
